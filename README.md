# Maintenance Dashboard

This project is a simple Node.js dashboard built with Express and EJS to track maintenance tasks. It allows you to add tasks with a status of Scheduled, In Progress, or Completed and view them in a table.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the application:
   ```bash
   npm start
   ```
3. Open your browser to `http://localhost:3000` to view the dashboard.

The application stores data only in memory, so tasks will reset when you restart the server.
