# Maintenance Dashboard

This project is a simple Flask-based dashboard to track maintenance tasks. It allows you to add tasks with a status of Scheduled, In Progress, or Completed and view them in a table.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser to `http://localhost:5000` to view the dashboard.

The application stores data only in memory, so tasks will reset when you restart the server.
